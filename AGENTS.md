# Инструкции для Codex

Это персональное офлайн-приложение Android, а не облачный сервис.

1. Прочитать `docs/specification.md`, `docs/architecture.md`, `docs/roadmap.md` до изменения кода.
2. Работать небольшими независимыми этапами, начиная только с alarm spike. Создавать отдельную ветку и PR; никогда не коммитить прямо в `main`.
3. Использовать Kotlin, Compose/Material3, Room, DataStore, Koin и нативные Android APIs по необходимости. Один Gradle-модуль app, без чрезмерной архитектуры.
4. Не менять утверждённое поведение без явного согласования. При конфликте требований указать проблему, предложить решение, но не выдавать собственное предположение за утверждённое.
5. Выполнять реальные команды сборки/тестирования и записывать их результат; не заявлять о проверке на Samsung без фактического ручного теста.
6. Не добавлять API, сервер, аналитику, телеметрию, импорт/экспорт или синхронизацию.
7. Беречь пользовательские данные. В релизах не использовать destructive migration и не логировать медицинские сведения.
8. В PR приводить изменённые файлы, выполненные проверки, ограничения и необходимый ручной чеклист.
