Реализовано 2026-11-03 в текущей feature/alarm-spike по явному указанию владельца.
Это разрешённое продолжение после этапа 1; старое ограничение «только этап 1»

Владелец подтвердил успешную ручную приёмку этапа 2 в чате 2026-11-03
и разрешил переход к этапу 3. Это отчёт владельца, а не проверка агентом на Samsung.

## Поведение

«Сегодня» показывает записи давления за текущую локальную дату; «История» — все
измерения в обратном порядке фактического времени. На обоих экранах есть ввод.
Почти квадратная кнопка «Давление» с иконкой тонометра сверху и подписью под ней
находится в фиксированной компактной строке
над нижней навигацией. Строка рассчитана на добавление других типов записей;
список занимает оставшееся место и не перекрывается кнопками. На экранах
лекарств и настроек эта строка скрыта.
После переноса кнопки ./gradlew assembleDebug testDebugUnitTest lintDebug
--warning-mode all — exit 0, BUILD SUCCESSFUL за 9s. UI-тест проверяет,
что нижняя граница списка находится выше кнопки, при прокрутке кнопка остаётся
на месте, открывает форму и отсутствует в настройках.
Дата и время в форме расположены в одной строке; календарь, часы и автопереход
фокуса сохранены. После последней правки ./gradlew assembleDebug testDebugUnitTest
lintDebug --warning-mode all — exit 0, BUILD SUCCESSFUL за 10s.
Тап по карточке открывает ModalBottomSheet для просмотра и изменения.
Удаление требует подтверждения. Лекарства и настройки остаются пустыми.

История и список за сегодня используют PressureHistoryCard в стиле формы:
две колонки с крупными значениями и подписями «Верхнее / Нижнее», метаданные
с иконкой часов, значок контекста с tooltip и отдельная строка пульса.
В карточках дата не дублируется: на «Сегодня» показан только текущий день,
в «Истории» записи сгруппированы по локальной дате с отдельным заголовком и иконкой календаря.
Фильтр «Сегодня» обновляется при возврате в приложение и наступлении полуночи.
Если пульс или контекст не указаны, соответствующий блок отсутствует.
Карточка целиком открывает прежний bottom sheet; исторические комментарии видны.
Схема, сортировка и операции хранения не менялись. Иконки контекста общие с формой.

После обновления истории ./gradlew assembleDebug testDebugUnitTest lintDebug
--warning-mode all — exit 0, BUILD SUCCESSFUL за 8s, без предупреждений.
Сквозной тест создания/открытия/удаления обновлён под семантику новой карточки.
Дополнительный UI-тест проверяет включение записи в 00:00 в «Сегодня», исключение
записи за мгновение до полуночи, отсутствие даты на «Сегодня» и заголовки дат
в «Истории». После группировки та же команда — exit 0, BUILD SUCCESSFUL за 8s.
Обновлённая группировка также визуально проверена в Preview.
Preview визуально проверены: светлая/тёмная темы 400×800, 400×500 со шрифтом 1.5.
На физическом Samsung оформление ещё не проверялось.

Обязательны положительные целые систолическое и диастолическое значения,
первое строго больше второго. Пульс необязателен, но при заполнении тоже положительный
целый. Контексты утро/день/вечер/ночь необязательны; ручной выбор не ограничен временем.
Для новой записи контекст выбирается автоматически по времени измерения:
ночь 00:00–05:59, утро 06:00–11:59, день 12:00–17:59, вечер 18:00–23:59.
Подтверждённое изменение даты или времени включает автовыбор и пересчитывает контекст,
в том числе после ручного выбора. Выбор иконки задаёт ручной контекст (повторный выбор
снимает его). Отдельной кнопки автовыбора нет. Отмена диалога или подтверждение
неизменённого значения сохраняют ручной контекст. При открытии существующей записи
её исходный контекст сохраняется.
Поле комментария удалено из компактной формы по указанию владельца.
При редактировании исторический комментарий сохраняется без изменения;
схема базы и старые значения не удаляются. Старые показания не подставляются в новую запись.
Форма открывается в ModalBottomSheet с частично раскрытым состоянием,
которое можно развернуть вверх. Закрытие при сохранении по-прежнему заблокировано.
Тест проверяет отсутствие поля комментария и сохранность исторической заметки.
После удаления поля и возврата частичного bottom sheet сборка, тесты и lint —
exit 0, BUILD SUCCESSFUL за 8s, без предупреждений.

Контексты представлены четырьмя векторными иконками в одной строке:
восход, солнце, закат и луна. Выбор выделен цветом; названия доступны через
contentDescription и tooltip при удержании. Области нажатия 56×56 dp.
После замены иконок ./gradlew assembleDebug testDebugUnitTest lintDebug --warning-mode all —
exit 0, BUILD SUCCESSFUL за 9s, без предупреждений. Preview проверены повторно.

Верхнее и нижнее давление расположены в одной строке. Все числовые поля
(включая пульс) используют крупный текст без рамки, подпись вынесена над вводом;
для accessibility подпись связана с редактируемым полем через contentDescription.
Автопереход фокуса сохранён. Обновлённые Preview проверены в 400×800 и 400×500
со шрифтом 1.5. ./gradlew assembleDebug testDebugUnitTest lintDebug --warning-mode all
после правки — exit 0, BUILD SUCCESSFUL за 7s, без предупреждений.
В тесте возврат фокуса в заполненное поле выполняется через semantics RequestFocus:
физический тап запускал не поддерживаемую Robolectric лупу Magnifier.

Подписи числовых полей сокращены до «Верхнее», «Нижнее», «Пульс».
Единицы и пометки «необязательно» из формы удалены. Заголовка даты/времени нет;
кнопки показывают иконки календаря/часов и значения. Названия кнопок сохранены
для accessibility. После сокращения подписей сборка, тесты и lint той же командой —
exit 0, BUILD SUCCESSFUL за 8s, без предупреждений.

Дата и время выбираются системными DatePickerDialog и TimePickerDialog (календарь
и часы, с учётом системного 12/24-часового формата), включая заднее число;
для отображения используется местный часовой пояс и формат дд.мм.гггг чч:мм;
в базе хранится epoch milliseconds. Новая запись имеет точность ввода до минуты.
При изменении других полей сохранённый measuredAt не округляется повторно.
createdAt сохраняется при редактировании, updatedAt обновляется.

Для проверки опечаток вне диапазонов 70–250 / 40–150 / пульс 30–220 требуется
подтверждение. Это технические границы предупреждения, не диагностическая оценка;
положительные значения вне диапазонов сохраняются после подтверждения.
Ошибки формата/сохранения оставляют редактор открытым. Стабильный UUID черновика
и IGNORE при повторной вставке предотвращают дубли. На время операции кнопки
и жест закрытия редактора отключены.

Автопереход фокуса при дописывании цифр:
- верхнее → нижнее: 70–99 после двух цифр, 100–250 после трёх;
- нижнее → пульс: 40–99 после двух цифр, 100–150 после трёх;
- пульс → время: 30–99 после двух цифр, 100–220 после трёх.

Удаление символов, восстановление черновика и открытие записи не переключают фокус.
Диапазоны управляют только фокусом; правила сохранения остаются прежними.
Два Compose-теста проверяют двух-/трёхзначный ввод, последовательность фокуса
и отсутствие перехода при удалении. Новые тесты дополнительно проверяют календарь,
изменение времени и даты с возвратом к автоконтексту, ручной выбор,
восстановление после пересоздания, отмену и подтверждение без изменения значения,
а также сохранение исходного контекста при открытии редактора.
Проверяются границы 06:00/12:00/18:00/00:00. Схема Room не менялась.
После добавления календаря/часов и автоконтекста:
./gradlew assembleDebug testDebugUnitTest lintDebug --warning-mode all —
exit 0, BUILD SUCCESSFUL за 9s, без предупреждений. На Samsung эти изменения
ещё не проверялись; проверить диалоги, поворот и ручное переопределение контекста.

Проверка автоперехода фокуса:
./gradlew assembleDebug testDebugUnitTest lintDebug --warning-mode all —
exit 0, BUILD SUCCESSFUL за 7s, без предупреждений.

## Хранение и миграция

Одна новая таблица blood_pressure: id TEXT primary key, systolic/diastolic INTEGER,
pulse nullable INTEGER, context nullable TEXT, comment TEXT, measuredAt/createdAt/
updatedAt INTEGER. Индекс measuredAt. Экспортированная схема — app/schemas/
dev.dadyarri.medtracker.alarm.AlarmDatabase/2.json.

Существующий файл alarm-spike.db сохранён. Автомиграция Room 1 → 2 добавляет
таблицу и индекс, сохраняя test_alarm и alarm_event. Destructive migration отсутствует.
DataStore и мастер не менялись. Медицинские значения в production не логируются.

Изменены MainActivity.kt, MedTrackerApplication.kt, AlarmDatabase.kt, app/build.gradle.kts
и README.md; добавлен пакет pressure (модель/DAO, ViewModel, экран), схема версии 2,
PressurePreviews.kt и пять тестовых классов pressure.
