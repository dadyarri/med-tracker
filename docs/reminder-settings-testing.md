# Настройки расписаний напоминаний

По запросу владельца добавлены ежедневные расписания давления, глюкозы,
завтрака, обеда, ужина и перекуса. Вес — раз в N недель, с выбранной
календарной опорной датой. Работа продолжается в текущей feature/alarm-spike.

## Уточнение владельца: единый режим глюкозы и Material 3

Отдельное ежедневное расписание глюкозы удалено из модели доступных расписаний;
старые ключи DataStore не читаются и не порождают план. Единственный режим —
трёхдневный цикл из Room, сохранённые параметры которого не менялись.
Цикл расположен карточкой в группе измерений: иконка, название, статус,
переключатель паузы, три дня со временем и кнопка интервала после еды.
Кнопка раскрытия отдельного раздела удалена. Перезапуск после паузы остаётся с дня 1.
Календарь опорной даты веса — Compose Material 3 DatePickerDialog/DatePicker,
подтверждение сохраняет именно выбранную дату через UTC, отмена ничего не меняет.
Эти уточнения заменяют старое описание отдельного ежедневного режима ниже.
Preview карточек веса/глюкозы 400×800 визуально проверен.
./gradlew build --warning-mode all после унификации — exit 0, 12s, без предупреждений.
ReminderSettingsUiTest проверяет Material 3 календарь (отмена без сохранения,
подтверждение без сдвига даты), переключатель цикла и изменение интервала.

## Поведение

Для каждого вида отдельная карточка с иконкой, временем через системные часы
и переключателем паузы. Время меняется и в приостановленном расписании.
Все новые расписания по умолчанию приостановлены.
Вес: N от 1 до 52, опорная дата выбирается календарём; частота считается
календарными неделями от даты, а не от последнего введённого веса.
Пауза сохраняет выбранные параметры и не изменяет опорную дату.

DataStore reminder_settings сохраняет paused/minute/weeks/anchor отдельно
для каждого вида; ошибка сохранения показывается, параллельные нажатия заблокированы.
База медицинских записей и Room-схема не менялись.

Существующий трёхдневный цикл глюкозы оставлен отдельным сворачиваемым разделом.
Он не заменяет запрошенное ежедневное расписание глюкозы.
CycleSettings теперь размещается внутри общей прокрутки без вложенного
вертикального скролла с неограниченной высотой.

## Граница реализации

Это настройки, их хранение и расчёт следующего срока. Системная доставка
новых расписаний через AlarmManager пока не подключена. Переключатель
сохраняет выбранное состояние расписания, но пока не назначает Android-сигнал.
Приостановленные расписания возвращают next = null. Следующие сроки
вычисляются строго в будущем/в текущий момент, прошлые даты не воспроизводятся.

## Проверки

- ./gradlew assembleDebug --warning-mode all — exit 0, 1s.
- ./gradlew build --warning-mode all — exit 0, 12s; debug/release,
  JVM-тесты и lint, без предупреждений.
- ReminderSettingsTest: ежедневные сроки всех видов кроме веса,
  пауза и возобновление, вес раз в 2 недели, опорная дата,
  отклонение ошибочного времени/частоты, локальное время при переходе DST.
- ReminderStoreTest: сохранение/чтение настроек новым экземпляром store,
  пауза сохраняет время, частоту и дату, остальные виды не меняются.

## Ручной чеклист

- [ ] Выбрать часы для каждого вида, выйти из настроек и перезапустить приложение.
- [ ] Приостановить/возобновить каждое расписание; выбранные часы сохраняются.
- [ ] Для веса выбрать 2–3 недели и дату календарём; проверить сохранность.
- [ ] Проверить поворот при открытых часах/календаре и вводе частоты.
- [ ] Проверить увеличенный шрифт и прокрутку к разделу цикла глюкозы.

На Samsung агентом не проверялось. Отдельная доставка и восстановление
напоминаний после reboot остаются незавершённой частью этапа.
