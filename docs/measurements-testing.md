# Этап 3: измерения и аналитика

2026-11-03. Переход разрешён владельцем после подтверждения приёмки давления.
По сохранённому указанию владельца работа продолжается в feature/alarm-spike.
Версия 0.5-measurements, versionCode 6. Реализация готова к ручной приёмке.

## Реализовано

- Вес: положительное значение, шаг 0,1 кг, дата/время, контекст и комментарий.
  Автоконтекст и ручное переопределение работают как у давления: изменение
  даты/времени возвращает автоматический выбор. Старые значения не подставляются.
- Глюкоза: положительное значение с точностью до двух знаков, ммоль/л или мг/дл,
  дата/время, натощак/до еды/после еды/без привязки, дополнительная характеристика
  перед сном/внепланово, комментарий. Оси контекстов независимы.
- Bottom sheet для ввода/изменения, календарь и часы в одной строке, числовая
  клавиатура, сохранение черновика при пересоздании, подтверждение удаления,
  защита повторного сохранения и открытая форма при ошибке.
- Новые кнопки с отдельными векторными иконками весов и капли, подпись под иконкой.
  Фиксированная строка над навигацией ограничивает область прокрутки.
- «Сегодня» содержит только текущую локальную дату. «История» объединяет все
  измерения, сортирует по фактическому времени и группирует по локальным датам.
  Фильтр типа даёт отдельные истории.
- Периоды 7/30/90 дней, всё время и произвольные включительные даты через календарь.
  Фильтры контекста давления/веса, отношения к еде и характеристики глюкозы.
- Графики и статистика раскрываются в истории. Вес — линия; давление —
  две линии на общей шкале; пульс — отдельный график только по заполненным фактам.
  У глюкозы цвет точек соответствует отношению к еде, есть легенда.
  Ось X использует фактические моменты, единственное измерение показано точкой.
  Линии соединяют реальные точки: промежуточные измерения и значения не создаются.
- Среднее, минимум, максимум, количество для каждой величины отдельно.
  Один и тот же отфильтрованный набор используется списком, графиками и статистикой.
- Единицы отображения глюкозы выбираются в истории и настройках, сохраняются
  в DataStore и используются по умолчанию в новой форме.

## Хранение и числовые правила

Отдельные таблицы Room weight и glucose; стабильный UUID, measuredAt,
createdAt/updatedAt, индексы measuredAt. Weight.tenthsKg — целое в десятых кг;
glucose.hundredths — целое в сотых исходной единицы, unit хранится вместе с записью.
Строки ввода разбираются через BigDecimal, поддерживаются точка и запятая,
избыточная точность и переполнение отклоняются, двоичные Float не используются
для хранения или статистики. Float применяется только для координат Canvas.

Отображение единиц: 1 ммоль/л = 18 мг/дл. Обратный перевод для вычислений —
до 6 знаков HALF_UP; показ и среднее — до 2 знаков HALF_UP. Просмотр/переключение
единиц истории не переписывает исходное измерение. Переключение единицы в редакторе
переводит текущее число с округлением до доступных двух знаков; сохранение —
явное действие пользователя. Редактор открывается в исходной единице записи.
При изменении других полей точность исходного measuredAt и createdAt сохраняется.

Необычные значения требуют подтверждения, а не запрещаются: вес вне 20–400 кг,
глюкоза вне 1–40 ммоль/л или 18–720 мг/дл. Это проверка вероятной опечатки,
без диагноза и медицинских рекомендаций. Положительные значения вне диапазонов
сохраняются после подтверждения.

База alarm-spike.db сохранена. Версия Room 3, автомиграция 2 → 3 добавляет
две таблицы без изменения давления, test_alarm и alarm_event.
Цепочка 1 → 2 → 3 сохранена, экспортированная схема 3.json включена в Git.
Destructive migration, сеть, телеметрия и логирование измерений не добавлялись.
